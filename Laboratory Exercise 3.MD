This project presents a functional input-output system based on an Arduino Uno. The Arduino Uno acts as the main controller to coordinate the user interaction and visual feedback.
The system is based on a 4x4 matrix keypad which is used for the user input and also a 7-segment display which displays numerical and alphabetical characters 0-9 and A-D according to the keypad entries.
The keypad and display are wired into the Arduino 's digital and analog pins respectively . This makes it easy for the system to associate pressing a particular button with the corresponding image on the display.
There is also a resistor to help limit current . In conclusion, the setup demonstrates the basics of microcontroller I/O management,
showing how to detect inputs through row-column scanning and integrate visual output logic to create a responsive interface.
