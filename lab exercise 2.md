This project uses an Arduino Uno, a 7-segment display, and push buttons connected through a breadboard.
The Arduino controls the whole circuit and sends signals to the display so it can show numbers. 
The buttons are used to change the output shown on the display, 
depending on how the program is written. Resistors are also included to prevent too much current from flowing through the components. Overall, the project is
a simple way to understand how coding and electronic circuits
can work together to create an interactive system.
